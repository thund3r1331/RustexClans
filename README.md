# 🏆 RustexClans (CRL)

> Соревновательный ладдер и система рейтингов для игры **Rustex Remake**.

Подробное описание архитектуры, регламента и правил для AI-агентов находится в [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md).

---

## 🌟 Ключевые возможности

- **Соревновательный ладдер (CRL)**: Рейтинг кланов с фильтрацией по тирам (Tier 1, Tier 2, Tier 3) и поиском.
- **Подиум лидеров**: Презентация топ-3 кланов сезона с анимированными эффектами.
- **Журнал рейдов (Audit Log)**: Публичная фиксация всех результатов сражений с видео-пруфами и никами модераторов.
- **Профили кланов**: Тег, состав игроков, логотип, описание, Discord и интерактивный график рейтинга.
- **Панель модерации**: Скрытая модалка управления для модераторов (активация клавишами `zxce`) с регламентными пресетами.
- **Высокая безопасность**: Brute-force защита с блокировкой IP, bcrypt-хеширование, изоляция создания пользователей, валидация загружаемых файлов без SVG, закрытый Swagger в продакшене.

## 🚀 Быстрый старт (Локальная разработка)

### 1. Бэкенд (Python + FastAPI)
```bash
cd backend
python -m venv .venv
# Windows:
.\.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
python main.py
```
API бэкенда запустится на `http://127.0.0.1:8000`.

### 2. Фронтенд (React + Vite + Tailwind)
```bash
cd frontend
npm install
npm run dev
```
Фронтенд запустится на `http://localhost:5173`.

### 3. Тестирование
```bash
python backend/tests/test_api.py
```

## 🛡️ Управление администраторами (CLI)

Создание пользователей через веб-интерфейс отключено в целях безопасности. Управление учетными записями осуществляется через консольную утилиту:

```bash
# Добавить или обновить пароль администратора
python backend/manage_admins.py --set <логин> <пароль> --role admin

# Показать список пользователей в базе
python backend/manage_admins.py --list

# Удалить пользователя
python backend/manage_admins.py --remove <логин>
```
